# Shadow Studio v0.33.0

- Quick Generate drafts and renders a video with current settings. It rotates saved gameplay when you have no clip selected.
- Custom Generate creates a script for editing before render. Choose genre, approximate duration, and an optional audience question.
- Set dialogue pacing and choose whether to export a separate SRT. Your voice selections and these production settings can be saved with a project.
- Both workflows use the existing review queue. Premium renders ask before using ElevenLabs.
