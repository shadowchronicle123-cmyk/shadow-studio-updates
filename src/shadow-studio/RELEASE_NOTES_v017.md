# Shadow Studio v0.17 — Prelaunch automation groundwork

**Working and tested**
- Owner-only API with timing-safe token comparison and disabled-by-default behavior.
- Read-only video inventory for the agent; local draft creation requires a reviewed/approved video.
- Publishing drafts from the browser interface with title, description, and desired privacy.
- Dashboard publishing draft queue and persistence across restarts.
- Existing v0.16 video preflight remains required to approve completed MP4s.

**Still unimplemented / not production verified**
- A directly connected ChatGPT app/plugin or remote hosted automation endpoint.
- Authenticated YouTube OAuth login, native publishing, scheduling, or analytics.
- Reliable premium narration on your Windows PC and high-quality 3-video batch test.
- Premium AI prompt-to-video, robust timeline editing, human-quality AI clipping.

The draft queue is metadata only. No media is uploaded or made public by this release.
