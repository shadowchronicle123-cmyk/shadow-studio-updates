# Shadow Studio v0.42.0

- Create Shorts in a two-stage Story and Voice & Gameplay workspace with a persistent preview, render status, and direct review action.
- Expand a custom premise offline, regenerate different twists and endings, or select an optional locally configured Ollama model.
- Export native 1080×1920 conversation videos with animated bubbles, synchronized timing, and adjustable gameplay height and crop.
- Approve an export before downloading its publishing kit. Optional private storage has a connection test, progress, and retry. The manual kit works without a storage provider.
- Run Windows and Linux acceptance checks, including an isolated upgrade and rollback rehearsal from the verified v0.41.0 package.

Offline custom stories use authored branches. The generator preserves the supplied premise, but some unusual scenarios fit the available plot branches better than others. Split caption timings within a spoken line remain approximate. S3 and vidIQ are optional. A publishing kit never authorizes public publishing.
