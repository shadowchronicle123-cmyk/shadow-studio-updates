# Shadow Studio v0.30 — Clipper and ElevenLabs Voice Picker

- Main and secondary-character voice selectors show available ElevenLabs account voices automatically; changes after connection are refreshed.
- Main and second-character audio previews, which can consume ElevenLabs API credits.
- YouTube and Twitch public HTTPS URL import for footage you own or are authorized to reuse. Some links may be blocked by providers or require authentication. Uses yt-dlp and FFmpeg.
- Auto clip: one 3–30-second vertical clip or three 3–10-second vertical clips. Three-clip export uses evenly spaced starting points when scene changes are sparse.
- Manual clipper accepts a file or authorized URL.
- The update feed/version increments to 0.30.0. Releases must be uploaded to the existing trusted GitHub Pages feed with matching SHA-256 checksum.
- No uploads to YouTube, no publishing and no live ElevenLabs requests were made during package creation.
